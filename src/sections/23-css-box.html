الـ Box Model: كل حاجة في الصفحة صندوق

أي عنصر بيترسم كـ صندوق: محتوى، وحواليه padding، وحواليه border، وحواليه margin. لو فهمت الطبقات دي وإزاي الـ display بيغيّر سلوكها، 80% من مشاكل الـ layout هتتحل لوحدها — ومن ضمنها سؤال أمني مهم: «العنصر ده مخفي فعلًا… ولا لسه بيتداس عليه؟»

الاختصارات: margin: 10px (الأربعة)، margin: 10px 20px (فوق/تحت، يمين/شمال)، margin: 5px 10px 15px 20px (فوق، يمين، تحت، شمال — مع عقارب الساعة). والـ logical properties بتمشي مع اتجاه الكتابة: margin-inline-start = «بداية السطر» (شمال في الإنجليزي، يمين في العربي)، وpadding-block = فوق وتحت.

box-sizing: أهم سطر في أي مشروع

الافتراضي content-box: الـ width للمحتوى بس، والـ padding والـ border بيتضافوا عليه — فـ width: 300px + padding: 20px = صندوق عرضه 340! الـ border-box بيخلي الـ width شامل كل حاجة، وده أسهل بكتير. كل المشاريع الحديثة بتبدأ بـ:

*, *::before, *::after { box-sizing: border-box; }

opacity: 0 = فخ الـ clickjacking

العنصر الشفاف لسه بياخد الضغطات — ده بالظبط اللي الـ clickjacking بيعتمد عليه (iframe شفاف فوق زرار). وفي التحليل: أي «مخفي» بـ CSS لسه موجود في الـ source والـ DOM — زي الـ SEO spam اللي شفناه بـ left:-9999px، وصفحات phishing بتخفي نصوص تخدع الفلاتر.

Margin collapse

الـ margins الرأسية بين عنصرين block ورا بعض بتنهار لأكبر واحد بدل ما تتجمع: margin-bottom: 30px + margin-top: 20px = مسافة 30 مش 50. وكمان margin أول ابن ممكن «يخرج» من أبوه. مش بيحصل في flex/grid، ولا أفقيًا، ولا مع padding/border على الأب.

المقاسات والـ overflow

  • width/height + min-width/max-width (الـ max بيمنع العنصر يبقى أعرض من كده على الشاشات الكبيرة). النسبة المئوية من عرض الأب.
  • توسيط block أفقيًا: max-width: 700px; margin-inline: auto; (أو margin: 0 auto).
  • overflow: visible (الافتراضي — بيطلع برا)، hidden (يتقص)، scroll، auto (scroll لو محتاج)، clip. ونص طويل في سطر: white-space: nowrap; overflow: hidden; text-overflow: ellipsis;.
  • outline زي الـ border بس مش بياخد مكان — عشان كده هو اللي بيستخدم لـ focus rings. متعملش outline: none من غير بديل (الدرس 31).
