Flexbox: ترتيب العناصر في صف أو عمود

قبل Flexbox، توسيط حاجة رأسيًا كان «لغز». دلوقتي: display: flex + سطرين. Flexbox مصمم لترتيب عناصر في اتجاه واحد (صف أو عمود) وتوزيع المساحة بينهم: navbars، toolbars، كروت جنب بعض، فورمز، وأي توسيط. وهو أساس كل framework حديث.

الكيبورد (Tab) وقارئ الشاشة بيمشوا على ترتيب الـ HTML مش الترتيب المرئي. لو قلبت الترتيب بالـ CSS، المستخدم اللي بالكيبورد هيتنطط بين العناصر بشكل غريب. غيّر ترتيب الـ HTML نفسه لو الترتيب له معنى.

💡
min-width: 0 السحري

عناصر الـ flex افتراضيًا مش بتصغر أقل من حجم محتواها (min-width: auto). نص طويل (URL أو token) جوه flex item هيكسر الـ layout — الحل: min-width: 0 على العنصر + overflow-wrap: anywhere.

container عليه `display: flex; flex-direction: column;`. عايز العناصر في النص أفقيًا. تستخدم إيه؟ `justify-content: center` `align-items: center` `text-align: center` `align-content: center` في `column` المحور الرئيسي رأسي، فالأفقي هو الـ cross axis ⇒ `align-items`. `justify-content` على المحور الرئيسي، وفي column ده الرأسي. الأفقي = cross axis = `align-items`. 3 عناصر عليهم `flex: 1` في container عرضه 600px (من غير gap). عرض كل واحد؟ حسب المحتوى 600px مش محدد 200px `flex: 1` = basis 0 وgrow 1 ⇒ المساحة كلها بتتقسم بالتساوي. `flex: 1` بيخلي الـ basis صفر، فكل المساحة (600) بتتوزع بنسب الـ grow (1:1:1). navbar: اللوجو على طرف واللينكات على الطرف التاني. أبسط حل؟ `display: flex; justify-content: space-between;` `float: left` و`float: right` `position: absolute` للاتنين `text-align: justify` `space-between` بيحط أول وآخر عنصر على الطرفين والباقي بالتساوي في النص. الـ floats والـ absolute حلول قديمة/هشة. Flexbox + space-between سطر واحد. عملت `order: -1` لزرار «Delete» عشان يبان الأول. مستخدم الكيبورد هيحس بإيه؟ هيوصله الأول مش هيقدر يوصله هيوصله بترتيبه في الـ HTML (مش المرئي) — فالـ focus هيتنطط بشكل مربك مفيش فرق `order` بصري بس. الترتيب المنطقي (Tab، قارئ الشاشة) = ترتيب الـ DOM.
