الصور: object-fit وaspect-ratio

object-fit: cover بيخلي الصورة تملا المكان من غير ما تتمط (وبيقص الزيادة)، وobject-position بيحدد أنهي جزء يفضل. وaspect-ratio: 16 / 9 بيحجز مساحة بنسبة ثابتة — مفيد جدًا ضد الـ layout shift.

«المستند متشوّش — سجّل دخول عشان تشوفه»

اللي فوق بالظبط هو template متكرر في phishing kits: صورة لمستند/فاتورة عليها filter: blur()، وفوقها modal زجاجي بـ backdrop-filter بيطلب الإيميل والـ password. مفيش ولا سطر JavaScript «مشبوه» — كله CSS، والمستند ممكن يكون حتى صورة data:. 🔎 للمحلل: blur على خلفية + فورم password في صفحة مرفقة = علامة قوية.

🎯 كل url() = request

/* loaded only when the element matches → reveals behaviour to the server */ .order-confirmed { background-image: url("https://track.example/px?event=purchase&id=8812"); } a:hover { background-image: url("https://track.example/px?event=hover"); } @media print { body { background-image: url("https://track.example/px?event=printed"); } }

الـ CSS مبيقدرش يقرا الـ response، بس يقدر يطلق requests حسب الحالة (عنصر ظهر، hover، طباعة، selector اتطابق). ده بيستخدم في tracking من غير JavaScript (حتى في إيميلات)، وده نفس السبب اللي بيخلي CSS injection خطير. 🛡️ الـ CSP img-src بيتحكم في صور الخلفية كمان.

✏️ تمارين الدرس 24

صورة hero لازم تملا مساحة 1200×400 من غير ما تتمط، ومش مهم لو اتقصّ جزء منها: `background-size: contain` `background-size: cover` `background-size: 100% 100%` `background-repeat: repeat` `cover` بيملا ويحافظ على النسبة (بيقص الزيادة)، و`contain` بيبيّن الصورة كلها (ممكن يسيب فراغ). `100% 100%` بتمط الصورة، و`contain` بتسيب فراغات. `cover` هو المطلوب. `background: linear-gradient(red, blue), url(photo.jpg);` — أنهي layer فوق؟ الصورة مبيعرضش غير واحدة حسب حجم كل واحدة الـ gradient (أول layer في القايمة بيترسم فوق) الطبقات بالترتيب: الأولى فوق. عشان كده بنحط gradient شفاف فوق صورة عشان النص يتقري. في الخلفيات المتعددة، أول قيمة = أعلى طبقة. CSS فيه `.paid { background: url(https://t.example/p?u=7) }`. الـ request ده بيتبعت إمتى؟ بس لما عنصر عليه `.paid` يتعرض في الصفحة أول ما ملف الـ CSS يتحمّل، دايمًا عمره ما بيتبعت بس لو فيه JavaScript المتصفح بيطلب صور الخلفية للعناصر اللي اتطابقت واتعرضت بس — وده اللي بيخلّي CSS يكشف «حالة» الصفحة للسيرفر. صور الخلفية بتتطلب لما قاعدة بيها تتطبق فعلًا على عنصر معروض. عايز دايرة 64×64 لصورة بروفايل مربعة أو مستطيلة من غير ما تتمط: `border-radius: 64px` `border-radius: 50%` بس `width/height: 64px` + `border-radius: 50%` + `object-fit: cover` `clip: circle` المقاس الثابت + نص قطر 50% + object-fit عشان الصور المستطيلة متتمطش. من غير `object-fit: cover` الصورة المستطيلة هتتمط جوه المربع.
