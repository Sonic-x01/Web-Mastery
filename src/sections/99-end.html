Cheat Sheet — HTML للـ Pentester

كل اللي محتاج ترجعله بسرعة في مكان واحد، وبيتحدّث مع كل جزء جديد من الكورس. اكتب في البحث أي كلمة (tag، attribute، context، حرف…).

🔎

هيكل المستند

  • <!DOCTYPE html>standards mode (من غيره quirks)
  • <html lang="ar" dir="rtl">اللغة والاتجاه
  • <meta charset="UTF-8">أول 1024 byte
  • <meta name="viewport" …>الموبايل
  • <title>إجباري · RCDATA
  • void: area base br col embed hr img input link meta source track wbr

النصوص والمعنى

  • h1–h6هيكل، من غير قفز
  • strong / bأهمية / لفت نظر
  • em / iتأكيد / صوت مختلف
  • code kbd samp varكود · مفاتيح · مخرجات · متغير
  • abbr title · time datetime
  • preبيحافظ على المسافات — مش raw text!
  • bdi · bdo dir · U+202ERLO spoofing

Entities

  • &lt; &gt; &amp;< > &
  • &quot; &#39;" '
  • &#60; &#x3C;decimal / hex
  • &nbsp; &copy; &colon; © :
  • بتتفك في: النص + الـ attributesمش في script/style
  • &amp من غير ;legacy: بتتفك (إلا قبل = أو حرف في attribute)

الروابط والـ URLs

  • page.htmlنفس الـ directory
  • ../x · /xلفوق · من الـ root
  • //host/xprotocol-relative = host تاني!
  • ?q=1 · #idquery جديدة · نفس الصفحة
  • #fragmentمبيتبعتش للسيرفر
  • rel="noopener noreferrer"للينكات الخارجية
  • <base href>أول واحد بس · CSP base-uri
  • downloadsame-origin / blob: / data: بس

الفورمز: إيه اللي بيتبعت

  • من غير nameمبيتبعتش
  • disabledمبيتبعتش
  • readonly · hiddenبيتبعتوا
  • checkbox مش متعلّممبيتبعتش · من غير value = on
  • selectالـ value مش النص
  • الـ submittername=value بتاعه
  • type="image"name.x · name.y
  • <button> جوه formsubmit افتراضيًا

enctype والـ method

  • application/x-www-form-urlencodedالافتراضي · space=+
  • multipart/form-dataللملفات · boundary
  • text/plainمن غير encoding · JSON CSRF
  • GETبيستبدل query الـ action
  • الأسطر الجديدةبتتبعت CRLF (%0D%0A)
  • formaction formmethod formenctype formtarget formnovalidateعلى الزرار
  • form="id"عنصر برا الفورم ينضم لها

Validation (UX مش حماية)

  • required
  • minlength maxlength
  • min max stepأرقام وتواريخ
  • patternبيطابق القيمة كلها
  • type=email|url|number
  • novalidate · formnovalidateاقفل
  • BypassDevTools · Burp · curl

الـ head

  • meta http-equiv="refresh"redirect · open redirect
  • meta name="referrer"no-referrer · strict-origin-when-cross-origin (افتراضي)
  • meta name="robots"طلب مش حماية
  • meta name="generator"version disclosure
  • script deferبعد الـ parsing بالترتيب
  • script asyncأول ما يوصل
  • type="module"deferred · strict
  • integrity + crossoriginSRI

iframe sandbox

  • sandbox فاضيكل القيود · origin opaque
  • allow-scriptsJS
  • allow-formsإرسال فورمز
  • allow-same-origin⚠ مع allow-scripts على نفس الـ origin = هروب
  • allow-popups · allow-modals
  • allow-top-navigation
  • srcdocorigin الأب (لو مش sandbox) · entities بتتفك
  • frame-ancestors / X-Frame-Optionsضد clickjacking (header بس)

Global attributes للـ recon

  • RCDATAtextarea title · entities أيوه، tags لأ
  • RAWTEXTstyle xmp iframe noembed noframes noscript*
  • Script datascript · أول </script> بيقفل
  • PLAINTEXTplaintext لآخر الملف

Contexts → encoding

  • HTML body& < > → entities
  • Attribute بـ quotes+ " ' → entities
  • Attribute من غير quotes❌ متعملش كده
  • URL (href/src)allow-list للـ scheme
  • JS string\xHH · < → < · أو JSON
  • Event handlerJS-escape ثم HTML-encode
  • CSSallow-list
  • Commentمتحطش داتا مستخدمين

طبقات الـ decoding

  • attributeHTML-decode الأول
  • javascript: URLثم percent-decode ثم JS

  • NFKC＜ → <
  • charsetBOM ← header ← meta ← تخمين

Handlers بتشتغل لوحدها (للاختبار المصرّح)

  • <svg onload=…> · <svg/onload=…>/ كفاصل
  • <details open ontoggle=…>
  • <audio src=x onerror=…>
  • <input autofocus onfocus=…>مش في iframe cross-origin
  • alert`1`من غير أقواس
  • <a href="javascript:…">محتاج ضغطة
