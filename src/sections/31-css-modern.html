CSS الحديث: متغيرات، nesting، وأدوات الشغل الحقيقي

الـ CSS اتطور جدًا: بقى فيه متغيرات بتتغير وقت التشغيل، و nesting، وfeature queries، وخصائص مسجّلة تتحرك. وفي المشاريع الحقيقية فيه طرق لتنظيم آلاف السطور (BEM، utility-first) وأدوات بتعالج الـ CSS قبل ما يتنشر. وفي آخر الدرس: إزاي ملف الـ CSS نفسه بيعمل recon لك.

Custom properties (متغيرات CSS)

:root { /* defined once, globally */ --accent: #7c3aed; --radius: 12px; --space: 16px; } .btn { background: var(--accent); border-radius: var(--radius); padding: calc(var(--space) / 2) var(--space); color: var(--btn-fg, white); /* fallback if --btn-fg is not defined */ } .btn.danger { --accent: #dc2626; } /* override the variable, not the property */
  • الاسم لازم يبدأ بـ --، وهو case-sensitive وبيتورّث للأبناء — فتقدر تغيّره لجزء من الصفحة بس (.btn.danger فوق).
  • مش زي متغيرات Sass: دي حيّة في المتصفح. تتغير في media query أو من JavaScript: el.style.setProperty("--accent", "#0ea5e9")، وتتقرا بـ getComputedStyle(el).getPropertyValue("--accent").
  • الـ fallback في var(--x, fallback) بيُستخدم لما المتغير مش متعرّف بس — مش لما قيمته غلط للخاصية.

calc(): خلط الوحدات

width: calc(100% - 2rem) = نسبة ناقص rem — حاجة مستحيلة من غير calc. لازم مسافات حوالين + و-: calc(100%-2rem) غلط والـ declaration كله بيتجاهل (الـ * و/ مش لازم). وبيشتغل مع المتغيرات: calc(var(--space) * 3).

Nesting (native)

.card { padding: 16px; border: 1px solid #e2e8f0; & .title { font-weight: 700; } /* = .card .title */ &:hover { border-color: #7c3aed; } /* = .card:hover */ &.featured { border-width: 3px; } /* = .card.featured */ @media (width >= 600px) { padding: 24px; } }

الـ & = الـ selector الأب. ده مدعوم في كل المتصفحات الحديثة (من 2023) من غير أي أداة. متعملش nesting أعمق من 2–3 مستويات — الـ specificity بتكبر والـ CSS بيبقى صعب.

@supports و@property

.gallery { display: flex; flex-wrap: wrap; } /* works everywhere */ @supports (display: grid) { .gallery { display: grid; } } /* upgrade if supported */ @supports selector(:has(a)) { /* … */ } /* test a selector */ @supports not (backdrop-filter: blur(4px)) { .glass { background: #fff; } }

الـ @property بيسجّل متغير بنوع (<angle>، <color>، <length>…) — فالمتصفح يقدر يحرّكه بنعومة (المتغير العادي بيتنطّ من قيمة لقيمة):

تنظيم الـ CSS في المشاريع الكبيرة

BEM

.block__element--modifier: .card، .card__title، .card--featured. أسماء واضحة، specificity واطية (class واحدة)، ومفيش تعارض.

Utility-first

classes صغيرة لكل خاصية: class="flex gap-4 p-6 rounded-xl" (Tailwind). سريع جدًا في الشغل، والـ build بيشيل اللي مش مستخدم.
