الخطوط

/* a font "stack": the first available wins, always end with a generic family */ body { font-family: "Cairo", "Segoe UI", system-ui, sans-serif; } code { font-family: "JetBrains Mono", Consolas, monospace; } /* self-hosted web font */ @font-face { font-family: "Cairo"; src: url("/fonts/cairo-var.woff2") format("woff2"); font-weight: 200 1000; /* variable font: one file, all weights */ font-display: swap; /* show fallback text immediately, swap when loaded */ unicode-range: U+0600-06FF, U+0020-007E; /* only download for these characters */ }

الخطوط والخصوصية

تحميل خط من fonts.googleapis.com = متصفح كل زائر بيبعت IP بتاعه لـ Google. محكمة في ميونخ (يناير 2022) اعتبرت ده مخالفة لـ GDPR لموقع ألماني. الحل الاحترافي: استضافة الخطوط على سيرفرك (woff2). 🎯 ومن الناحية الهجومية: الـ unicode-range بيخلي المتصفح يحمّل ملف الخط بس لو حرف معيّن ظهر في الصفحة — وده اتستغل في هجمات CSS injection لمعرفة الحروف الموجودة في نص.

ليه `rem` أحسن من `px` لأحجام الخطوط؟ أسرع في الرسم بيشتغل في كل المتصفحات وpx لأ بيتناسب مع حجم خط الـ root، فبيحترم المستخدم اللي كبّر الخط الافتراضي في إعدادات المتصفح مفيش فرق Accessibility: مستخدمين ضعاف النظر بيكبّروا الخط الافتراضي، والـ px الثابت بيتجاهل ده. الفرق في الـ accessibility: الـ rem بيكبر مع إعداد المستخدم، الـ px لأ. `.a { font-size: 2em }` جوه `.a` جوه `.a`، والـ root = 16px. حجم الخط في التالت؟ 128px 32px 96px 64px 16 × 2 × 2 × 2 = 128. ده «الـ em compounding» — والـ rem مبيعملوش. الـ em في font-size نسبة لخط الأب، فكل مستوى بيضرب في 2: 32 → 64 → 128. `border: 1px solid currentColor` على عنصر `color: #2563eb`. لون الـ border؟ أسود شفاف لون الأب `#2563eb` `currentColor` = قيمة `color` على نفس العنصر. `currentColor` بيرجع لقيمة خاصية `color` على العنصر نفسه. نص عربي عليه `letter-spacing: 2px`. المشكلة؟ مفيش الحروف العربية المتصلة بتتفصل عن بعض وشكل الكلمات بيبوظ النص بيتقلب الخط بيصغر العربي مكتوب متصل؛ الـ letter-spacing بيكسر الوصلات. المسافة بين الحروف بتقطع الوصل بين حروف العربي المتصلة. `font-family: "MyFont", Arial;` و"MyFont" مش متحمّل. إيه اللي هيحصل؟ النص مش هيظهر الخط الافتراضي للمتصفح (Times) Arial — أول خط متاح في الـ stack error ودايمًا اختم الـ stack بـ generic family (`sans-serif`، `serif`، `monospace`). المتصفح بيمشي على القايمة بالترتيب وبياخد أول خط متاح.

الـ html سيبه على الافتراضي (16px). اكتب بالـ rem:

  • h1: 2rem (= 32px)، p: 1rem، small: 0.875rem.
  • الـ p: line-height: 1.6 من غير وحدة، وmax-width: 65ch.
  • ممنوع px في أحجام الخطوط.
