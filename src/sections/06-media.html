الصور والوسائط وSVG

صورة واحدة في صفحة = request أوتوماتيك بيطلع من متصفح الزائر من غير ما يدوس على حاجة. الحقيقة البسيطة دي ورا tracking pixels في الإيميلات، وCSRF بالـ GET، وأشهر payload XSS في التاريخ (onerror). وفي الآخر SVG: «صورة» هي في الحقيقة مستند فيه scripts — وبقت من أشهر مرفقات الـ phishing.

SVG جوه الصفحة: صورة… ومستند

SVG (Scalable Vector Graphics) = صورة متوصفة بـ markup (أشكال وإحداثيات) بدل pixels. تقدر تكتبه inline جوه الـ HTML مباشرة، وساعتها كل شكل جواه element في الـ DOM تقدر تعمله style وتحرّكه:

SVG

جوه <svg> الـ parser بيدخل «foreign content»: الـ self-closing (<circle/>) بيشتغل فعلًا، وأسماء زي viewBox وforeignObject ليها حروف كابيتال، وقواعد تانية مختلفة. 🎯 الاختلافات دي هي أساس payloads وbypasses كتير (الدرس 13).

SVG upload = stored XSS كلاسيكي

موقع بيسمح برفع «صورة» SVG كـ avatar ويخدمها من نفس الدومين بـ Content-Type: image/svg+xml. جوه الـ avatar في الصفحة (كـ img) مفيش مشكلة. بس لو المهاجم بعت للضحية لينك الملف نفسه (https://shop.example/uploads/me.svg)، المتصفح بيفتحه كمستند والـ script بيشتغل على shop.example = XSS. الحلول: تخدم الـ uploads من دومين منفصل، أو Content-Disposition: attachment، أو CSP على الـ uploads، أو تحويل/تنظيف الـ SVG.

🦠
SVG كمرفق phishing

من 2024 الـ SVG attachments بقت من أشهر أشكال الـ phishing: الإيميل فيه ملف .svg، ولما الضحية تفتحه بيتفتح في المتصفح (مش في عارض صور)، والـ JavaScript جواه بيعرض صفحة login مزيفة أو بيعمل redirect لموقع المهاجم — وكتير منه بيكون فيه الـ URL متشفّر بـ Base64. أدوات الفحص التقليدية كانت بتعامله كـ «صورة» فبيعدّي.

Tracking pixels وCSRF بالـ GET

صورة 1×1 شفافة في إيميل = لما الإيميل يتفتح، برنامج الإيميل يطلب الصورة، فالمرسل يعرف إن الإيميل اتفتح وإمتى ومن أنهي IP وبأي client — والـ id في الـ URL بيحدد الضحية. (برامج الإيميل الحديثة بتعمل proxy للصور أو بتمنعها افتراضيًا لنفس السبب.) ونفس الآلية: لو أي endpoint بيعمل action بـ GET، أي صفحة تحط <img> بالـ URL ده هتنفّذه بالـ cookies بتاعة الضحية.

🦠
Data URIs في الـ phishing kits

صفحات الـ phishing بتحط لوجو البنك أو Microsoft كـ data:image/png;base64,… جوه الـ HTML بدل ما تطلبه من موقعهم — عشان (1) الـ brand ميشوفش requests غريبة لملفاته، (2) الصفحة تشتغل offline كمرفق. ككاشف: Base64 طويل جوه src في مرفق إيميل = علامة.
