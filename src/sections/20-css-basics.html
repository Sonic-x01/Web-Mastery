CSS: إزاي الصفحة بتاخد شكلها

الـ HTML بيقول «ده إيه»، والـ CSS (Cascading Style Sheets) بيقول «يبان إزاي»: الألوان، الخطوط، المسافات، الأماكن، الحركة، وشكل الصفحة على الموبايل. للمطوّر: ده اللي بيحوّل HTML نضيف لمنتج حلو. وللـ pentester: الـ CSS بيقرر إيه اللي «باين» وإيه اللي «مستخبي» — وأساس الـ clickjacking وإخفاء المحتوى في الـ phishing، وكمان طريقة لسرقة بيانات من غير ولا سطر JavaScript.

DevTools هو أهم أداة CSS

تاب Elements → Styles: كل القواعد اللي بتنطبق على العنصر، والمشطوب = اتغلب عليه، وعلامة ⚠️ = declaration غلط. تاب Computed: القيمة النهائية ومنين جت. تقدر تعدّل لايف، وتعمل :hov عشان تجرّب :hover و:focus. وأي تعديل في DevTools بيروح مع الـ refresh — انقله لملفك.

🎯
CSS من منظور أمني

(1) style="…" وأي input بيدخل في CSS = CSS injection. (2) الـ CSP بيتحكم في الـ CSS بـ style-src — والـ inline styles محتاجة 'unsafe-inline'. (3) الـ CSS بيقرر إيه اللي المستخدم شايفه: زرار شفاف فوق زرار، نص مخفي، صفحة login مزيفة full-screen — كله CSS.
