النصوص والمعنى والـ Entities

HTML مش بتقول «خلّي ده bold»؛ بتقول «ده مهم» أو «ده كود» أو «ده اختصار». المعنى ده (الـ semantics) بيقرا منه قارئ الشاشة ومحرك البحث والـ scrapers. وفي آخر الدرس أهم موضوع أمني فيه: الـ character references — إزاي تكتب < كنص من غير ما المتصفح يفتح tag، وده أساس الحماية من XSS.

العناوين: h1 → h6

ستة مستويات، والرقم = الترتيب في الهيكل مش الحجم (الحجم بيتعمل بالـ CSS). القواعد العملية: h1 واحد للموضوع الرئيسي، وبعده h2 للأقسام، وh3 جوه الـ h2… ومتنطّش مستوى (من h2 لـ h4). مستخدمين قارئات الشاشة بيتنقلوا في الصفحة بالعناوين زي فهرس.

الكود والنص المنسّق: pre + code

<pre> بيحافظ على المسافات والأسطر، و<code> جواه بيقول «ده كود». بس خلّي بالك: pre مش raw text — الـ tags جواه بتتفسّر عادي! عشان تعرض كود HTML كنص لازم تعمل escape للـ < و&:
