أساسي▼

  1. الهيكل: DOCTYPE، lang، charset أول حاجة، viewport، title، description، وheader/nav/main/footer.

  6. Stretch: JSON-LD من نوع Person، وskip link، واختبرها بالكيبورد وLighthouse.

03

Login + Registration: صح… وبعين المهاجم

متوسط▼

جزئين: (أ) تبني فورمين احترافيين، (ب) تكتب تحليل «إيه اللي بيتبعت وإيه اللي ممكن يتعدّى». الدروس: 08، 09، 12.

  1. Login: POST، autocomplete="username" و"current-password"، labels، «remember me» checkbox بقيمة صريحة، وhidden csrf_token.
  2. Registration: fieldset/legend، username بـ pattern، email، password بـ minlength=12 و"new-password"، تأكيد الـ password، country select، terms (required)، وزرار «Show password» بـ type="button".
  3. ابعت كل فورم في المعاينة/المعمل، وانسخ الـ HTTP request بالظبط.
  4. التحليل: جدول لكل قيد في المتصفح (required، pattern، maxlength، select، hidden…) وإزاي يتعدّى (DevTools / formnovalidate / Burp)، والـ check المطلوب في السيرفر.
  5. Stretch: ضيف formaction خبيث كأنه HTML injection واكتب الـ finding وإصلاحه (CSP form-action + encoding).

دفتر الـ Contexts: ثغرة وإصلاحها في 5 أماكن

متقدم▼

صفحة مرجعية ليك: لكل context (body، attribute بـ quotes، attribute من غير quotes، JS string، URL) — الكود الضعيف، الـ payload، ليه شغّال، والكود المصلّح. شرط صارم: ولا payload يتنفّذ في الصفحة نفسها. الدروس: 13، 14، 16.

  1. لكل context: figure فيه pre للكود الضعيف، وpre للـ payload، وشرح، وpre للإصلاح.
  2. كل الـ HTML المعروض escaped (افتح 🌳 DOM: لازم مايبقاش فيه ولا img ولا script زيادة).
  3. اختبر كل payload في الـ XSS Range أو المعمل قبل ما تكتبه.
  4. Stretch: ضيف context سادس (comment أو RCDATA) وسابع (event handler).

06

PoC Kit: Clickjacking + Form hijacking

متقدم▼

صفحتين PoC جاهزين تحطهم في أي تقرير (بعد ما تغيّر الـ URL): واحدة clickjacking بـ slider للشفافية، وواحدة توضّح form hijacking. الدروس: 09، 11، 16.

  1. Clickjacking: iframe للـ target فوق زرار طُعم، مع input type="range" بيغيّر الـ opacity (عشان العميل يشوف الطبقتين)، ونص بيشرح الخطوات.
  2. إثبات إن الـ framing ممكن: لو الـ iframe فضي/رفض، اكتب في التقرير الـ headers اللي منعته.
  3. Form hijack: صفحة فيها فورم «حقيقية» + الـ injection (زرار بـ form وformaction)، والـ request الناتج.
  4. Remediation في الصفحة نفسها: frame-ancestors، form-action، encoding.

ألغاز الـ Parser

متقدم▼

لكل لغز: اكتب أقصر HTML ينتج الـ DOM المطلوب، واتأكد بالـ Parser Playground (الدرس 13). الهدف إنك تتنبأ بالـ parser من غير ما تجرّب.

  1. <div> مكتوب بعد <p> مفتوحة يطلع أخوها مش ابنها — من غير ما تكتب </p>.
  2. <i> يظهر مرتين في الـ DOM مع إنك كتبته مرة واحدة (adoption agency).
  3. نص مكتوب جوه <table> يطلع قبلها (foster parenting).
  4. <img> مكتوب جوه <svg> يطلع برّاه.
  5. الـ input واقع هنا: <title>INPUT</title>. اكتب INPUT بحيث يتعمل <b> حقيقي في الصفحة (تلميح: اقفل الـ RCDATA).
  6. نفس النص يدّي DOM مختلف حسب الـ scripting flag (noscript).

🦠 Triage لمرفق Phishing بصيغة HTML

متقدم▼

مرفق اسمه Shared_Document.html وصل لموظف. شغلك: تحليل static الأول، بعدين «تفجير» آمن في sandbox التحليل (مفيش network، وكل sink بيتسجّل)، وفي الآخر قايمة IOCs. الدروس: 06، 10، 14، 15. (العينة دي تعليمية ومن تأليفنا، والدومينات من نطاق التوثيق .example.)

  1. Static: اقرا الملف كنص. علّم كل حاجة مشبوهة: refresh، data URI، hidden inputs، strings متقسّمة، atob/unescape/document.write.
  2. Decode: فك الطبقات بالـ Encoder (الدرس 14) من غير تشغيل.
  3. Detonate: دوس «🧪 شغّل في sandbox التحليل» وقارن الـ sinks باللي فكّيته بإيدك.
  4. IOCs: جدول بالـ domains/URLs، الـ victim identifiers، الـ lure text، والتقنيات (techniques).

🏁 Capstone: صفحة تسجيل آمنة (بتتصحح أوتوماتيك)

ابني صفحة تسجيل بتجمع أهم قواعد الجزء الأول. الاختبارات بتتشيك على كل نقطة:

  • مستند سليم: DOCTYPE، lang، meta charset أول عنصر في الـ head، title.
  • meta name="referrer" content="no-referrer".
  • فورم POST لـ /signup: email (type=email، required، autocomplete="email")، password (required، minlength=12، autocomplete="new-password")، hidden csrf_token بقيمة مش فاضية، وزرار submit — وكل خانة ظاهرة ليها label.
  • iframe للشروط (/terms.html) عليه title وsandbox من غير allow-same-origin.
  • أي لينك خارجي (https://) بـ target="_blank" عليه rel فيه noopener.
  • ممنوع: أي on… attribute، أي javascript: URL، وأي <script>.
