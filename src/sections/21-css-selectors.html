الـ Selectors: إزاي تختار أي عنصر بالظبط

الـ selector هو «عنوان» القاعدة: بيحدد العناصر اللي الـ CSS هيتطبق عليها. نفس اللغة دي بتستخدمها في JavaScript (querySelectorAll)، وفي أدوات الـ scraping والاختبار (Playwright، Selenium)، و— للـ pentester — في هجمات CSS injection اللي بتسرق داتا حرف حرف عن طريق attribute selectors.

الـ selector «بيقرا» القيم

input[name="csrf"][value^="a"] بيطابق بس لو الـ token بيبدأ بـ a. لو المهاجم قدر يحقن CSS، يكتب قاعدة لكل حرف محتمل، وكل قاعدة تطلب صورة خلفية من سيرفره — فالسيرفر يعرف أول حرف من الـ token. وبعدين التاني… ده CSS exfiltration. كله من غير ولا سطر JavaScript.

content: attr() والمحتوى اللي «مش موجود»

النص اللي بيطلع من ::before/::after مش في الـ DOM ومش بيتلاقي بـ Ctrl+F في الـ source بسهولة — صفحات phishing بتستخدم ده عشان كلمات زي «Microsoft» أو «Password» متبقاش موجودة كنص قدام الفلاتر، وتظهر للضحية بس. ولو قدرت تحقن CSS، content: attr(value) يقدر «يعرض» قيم مخفية زي tokens.

📜
:visited متقيّد عشان الخصوصية

زمان كان أي موقع يقدر يعرف تاريخ تصفحك: يحط لينكات لمواقع كتير، ويشوف أنهي واحد لونه «visited» بـ getComputedStyle. دلوقتي المتصفحات بتسمح بخصائص ألوان بس في :visited، والـ getComputedStyle بيكدب ويرجّع قيمة الـ unvisited. (الهجمات بقت side-channels أعقد، والمتصفحات بتقسّم الـ history حسب الموقع.)

إيه الفرق بين `div .note` و`div.note`؟ مفيش فرق الأول: أي `.note` جوه div. التاني: div نفسه عليه class note الأول غلط في الـ syntax التاني: أي `.note` جوه div المسافة combinator (descendant). من غير مسافة = نفس العنصر عليه الشرطين. المسافة بين جزئين = «جوه». لزقهم = «نفس العنصر». أنهي selector بيختار اللينكات اللي بتروح لملفات PDF حتى لو الامتداد مكتوب `.PDF`؟ `a[href*="pdf"]` `a[href^=".pdf"]` `a[href$=".pdf"]` `a[href$=".pdf" i]` `$=` = بيخلص بـ، و`i` = case-insensitive. محتاج «بيخلص بـ» (`$=`) ومن غير ما الحروف تفرق (`i`). `*=` هيطابق حاجات زي `/pdfs/page.html`. `li:nth-child(-n+3)` بيختار إيه؟ أول 3 عناصر آخر 3 عناصر كل تالت عنصر ولا حاجة (n سالب) n = 0، 1، 2… ⇒ 3، 2، 1، 0، -1… والمواضع الموجبة بس هي اللي بتتحسب: 1 و2 و3. عوّض n = 0، 1، 2، 3…: النتايج 3، 2، 1، 0… والمواضع الصالحة 1–3 = أول 3. عايز تلوّن `label` لو الـ `input` اللي جواه متعلّم عليه. أنهي selector؟ `input:checked label` `label + input:checked` `label:has(input:checked)` `label:checked` `:has()` بيخليك تختار الأب حسب اللي جواه — حاجة كانت مستحيلة في CSS قبل كده. الـ combinators العادية بتنزل لتحت أو لقدام بس. عشان «الأب اللي جواه» محتاج `:has()`. `a::after { color: red; }` ومفيش ولا نص اتضاف. ليه؟ `::after` مش بيشتغل على اللينكات لازم `content` (حتى لو فاضي `""`) عشان الـ pseudo-element يتعمل لازم `:after` بنقطة واحدة الـ color مش مسموح فيه من غير `content`، `::before`/`::after` مش بيتولّدوا أصلًا. القاعدة الأساسية: `content` إجباري لـ `::before` و`::after`. ليه مبقاش ينفع موقع يعرف المواقع اللي زرتها عن طريق `:visited` و`getComputedStyle`؟ `:visited` اتشال من CSS المتصفح بيمسح الـ history بيشتغل على HTTPS بس المتصفحات بتسمح بخصائص ألوان بس في `:visited`، و`getComputedStyle` بيرجّع قيمة اللينك العادي ده mitigation مقصود لهجمات history sniffing. `:visited` لسه موجود، بس متقيّد جدًا لأسباب خصوصية.
