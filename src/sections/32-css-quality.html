CSS احترافي: Accessibility، أداء، طباعة، وDebugging

الفرق بين CSS «شغال» وCSS احترافي: إن كل الناس تقدر تستخدم الصفحة (لوحة مفاتيح، قارئ شاشة، نظر ضعيف)، وإنها تفتح بسرعة، وتتطبع كويس، وإنك تعرف تلاقي أي مشكلة في دقايق. وكـ pentester: هتفهم ليه «الزرار المستخبي بـ CSS» مش حماية.

التباين (contrast)

الـ WCAG بتقيس التباين بنسبة من 1:1 (نفس اللون) لـ 21:1 (أسود على أبيض) محسوبة من «الإضاءة النسبية» للونين. الحد الأدنى (مستوى AA):

العنصرAAAAA
نص عادي4.5:17:1
نص كبير (24px+، أو 18.66px+ bold)3:14.5:1
مكونات الواجهة (حدود الـ inputs، أيقونات، الـ focus ring)3:1—

لاحظ: #767676 على أبيض = 4.54 (بيعدّي)، و#777777 = 4.48 (مش بيعدّي) — فرق مش باين للعين. عشان كده بتقيس، مش بتخمّن. DevTools بيوريك النسبة لما تدوس على أي لون في الـ Styles، وLighthouse بيفحص الصفحة كلها.

الـ focus: لوحة المفاتيح لازم تشوف هي فين

/* ❌ never — keyboard users get lost */ a:focus, button:focus { outline: none; } /* ✅ a clear ring for keyboard users; mouse clicks don't show it */ :focus-visible { outline: 3px solid #2563eb; outline-offset: 2px; } /* sticky header? keep the focused element from hiding under it */ html { scroll-padding-top: 80px; }

الـ :focus-visible بيتحقق لما المتصفح يقرر إن المستخدم محتاج يشوف الـ focus (لوحة مفاتيح غالبًا)، فالشكل بيفضل نضيف للماوس ومفيد للكيبورد. جرّب الصفحة دي نفسها بـ Tab وShift+Tab.

Skip link: أول لينك في الصفحة «Skip to content»، مستخبي لحد ما ياخد focus — بيوفّر على مستخدم الكيبورد إنه يعدّي على 30 لينك في الـ nav كل صفحة.

قواعد a11y تانية لازم تبقى عادة

  • متعتمدش على اللون لوحده: الخطأ في form = لون أحمر + أيقونة + نص. حوالي 1 من كل 12 راجل عنده عمى ألوان.
  • الأحجام بالـ rem عشان تحترم حجم الخط اللي المستخدم اختاره، والصفحة لازم تفضل مقروءة عند zoom 200% ومن غير scroll أفقي عند عرض 320px.
  • Target size: أي حاجة بتتداس لا تقل عن 24×24px (والأحسن 44×44 على الموبايل).
  • @media (forced-colors: active): وضع High Contrast في Windows بيلغي ألوانك — الـ backgrounds بتختفي، فخلّي الحدود والـ outlines هي اللي بتوضّح الأزرار.
  • @media (prefers-contrast: more) للي طالب تباين أعلى، وprefers-reduced-motion (الدرس 29).

الأداء

الـ CSS بيوقف الرسم

أي <link rel="stylesheet"> في الـ head هو render-blocking: الصفحة مش بتترسم لحد ما يتحمّل. خلّيه صغير، وحط الـ «critical CSS» (اللي محتاجه أول شاشة) inline، وابعد عن @import جوه CSS (بيعمل requests ورا بعض).

الخطوط

font-display: swap = النص يظهر فورًا بخط احتياطي لحد ما الخط ينزل. و<link rel="preload" as="font" type="font/woff2" crossorigin> للخط الأساسي. استخدم woff2 بس.

CSS مش مستخدم

DevTools ← Ctrl+Shift+P ← «Coverage»: بيوريك نسبة الـ CSS اللي اتنفذت فعلًا. مكتبات كاملة بتتحمّل عشان 3 classes!

صفحات طويلة

content-visibility: auto على الأقسام البعيدة = المتصفح ميعملهاش layout ولا paint لحد ما تقرب من الشاشة (مع contain-intrinsic-size عشان الـ scrollbar).

الطباعة: تقارير شكلها محترم

تقرير الـ pentest أو الفاتورة غالبًا هيتحفظ PDF من المتصفح (Ctrl+P). @media print بيخلّيه نضيف:

@media print { nav, .no-print, .chat-widget { display: none; } body { color: #000; background: #fff; font-size: 11pt; } a[href^="http"]::after { content: " (" attr(href) ")"; font-size: 9pt; } /* links stay readable on paper */ .finding, table, pre { break-inside: avoid; } /* don't split a finding across pages */ h2 { break-after: avoid; } } @page { margin: 18mm; }

جرّبه في DevTools: Rendering ← «Emulate CSS media type: print».

Debugging الـ CSS زي المحترفين

1

Styles pane

declaration متشطّب = في قاعدة أقوى غلبته (الدرس 21). مثلث أصفر = اسم خاصية أو قيمة غلط (typo) فالمتصفح تجاهلها. ودوس على :hov عشان تجبر :hover/:focus.

2

Computed

القيمة النهائية لكل خاصية، ودوس على السهم يوديك للقاعدة اللي كسبت بالظبط.

3

Layout overlays

شارة grid/flex جنب العنصر في الـ Elements بتعرض الخطوط والـ gaps. و«عنصر بيعمل scroll أفقي؟» حط مؤقتًا * { outline: 1px solid rgb(255 0 0 / .4); } وهتلاقيه فورًا.

4

الدعم والجودة

قبل ما تستخدم feature جديدة: MDN (جدول الـ compatibility) وcaniuse، وعلامة Baseline (Widely / Newly available). وفي المشروع: Stylelint بيمسك الأخطاء والتكرار، وPrettier بيوحّد التنسيق.

Pentester: الإخفاء بـ CSS مش صلاحيات

زرار «Delete user» عليه display: none للمستخدم العادي، أو form متقفل بـ pointer-events: none وopacity: .5، ده كله شكل بس. الـ request لسه ممكن يتبعت: اقرا الـ HTML/JS واعرف الـ endpoint، وابعته بنفسك من Burp بحساب مستخدم عادي. لو السيرفر نفّذه = Broken Access Control (رقم 1 في OWASP Top 10). والعكس كـ developer: كل صلاحية لازم تتحقق على السيرفر.
