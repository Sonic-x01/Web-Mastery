CSS Grid: Layouts في بُعدين

Flexbox ممتاز لصف أو عمود. Grid بيتحكم في الصفوف والأعمدة مع بعض: layout الصفحة كلها (header، sidebar، محتوى، footer)، dashboards، معارض صور بتتظبط لوحدها على أي شاشة من غير ولا media query. القاعدة العملية: Grid للـ layout، وFlexbox للـ components — وغالبًا هتستخدم الاتنين مع بعض.

الأساسيات: الأعمدة والـ fr

.grid { display: grid; grid-template-columns: 200px 1fr 2fr; /* fixed + 1 share + 2 shares of what's left */ grid-template-rows: auto 1fr; gap: 16px; /* row-gap + column-gap */ } /* repeat + minmax: as many 160px+ columns as fit, stretched to fill */ .gallery { display: grid; grid-template-columns: repeat(auto-fit, minmax(160px, 1fr)); gap: 12px; }
  • fr = «حصة» من المساحة الفاضية بعد طرح الأعمدة الثابتة والـ gaps.
  • repeat(3, 1fr) = 3 أعمدة متساوية. minmax(160px, 1fr) = مش أقل من 160 ومش أكتر من حصة.
  • auto-fit مقابل auto-fill: الاتنين بيحطوا أكبر عدد أعمدة ممكن؛ auto-fit بيلم الأعمدة الفاضية فالعناصر تتمط وتملا الصف، وauto-fill بيسيب أعمدة فاضية.

التحكم في مكان العنصر

الـ grid ليه خطوط مترقّمة من 1 (والسالب من الآخر: -1 = آخر خط). العنصر بتحدد بداية ونهاية:

الكودالمعنى
grid-column: 1 / 3من خط 1 لخط 3 = عمودين
grid-column: span 2عمودين من مكانه الطبيعي
grid-column: 1 / -1العرض كله (من أول خط لآخر خط)
grid-row: 2 / span 3من الصف 2، تلات صفوف

Grid ضمني ومحاذاة

  • لو العناصر أكتر من الخلايا المتعرّفة، الـ grid بيعمل صفوف جديدة ضمنية: حجمها بـ grid-auto-rows (مثلًا minmax(100px, auto)).
  • grid-auto-flow: dense بيملا الفراغات بعناصر جاية بعدين (بيغيّر الترتيب المرئي — نفس تحذير الـ accessibility بتاع order).
  • justify-items/align-items (أو اختصار place-items) = محاذاة المحتوى جوه كل خلية. place-items: center على grid = أقصر توسيط في CSS.
  • subgrid: عنصر جوه grid يقدر يورث خطوط أبوه (grid-template-columns: subgrid) — بيخلي كروت متجاورة عناوينها وأزرارها على نفس الخط.

إمتى تختار Grid بدل Flexbox؟ دايمًا، Flexbox قديم لما يبقى عندك عنصر واحد لما محتاج تتحكم في الصفوف والأعمدة مع بعض (layout في بُعدين) لما محتاج توسّط نص Grid = بُعدين، Flexbox = بُعد واحد. والاتنين بيتجمعوا عادي (grid للصفحة، flex جوه الكروت). الفرق الجوهري: Flexbox لصف أو عمود، Grid للاتنين مع بعض. `grid-column: 1 / -1` معناها إيه؟ العنصر بياخد عرض الـ grid كله عمود واحد آخر عمود بس العنصر مخفي من أول خط لآخر خط (السالب بيعد من الآخر) — ممتاز للعناوين والـ banners. `-1` = آخر خط. فمن 1 لـ -1 = كل الأعمدة. `repeat(auto-fit, minmax(200px, 1fr))` في container عرضه 650px (من غير gap). كام عمود؟ 4 2 1 3 3 × 200 = 600 ≤ 650، و4 × 200 = 800 أكبر. فـ 3 أعمدة وكل واحد بيتمط لـ 216.67px. أكبر عدد أعمدة كل واحد فيهم ≥ 200 في 650: 3. والباقي (50) بيتوزع عليهم. إيه الفرق العملي بين `auto-fit` و`auto-fill` لو العناصر قليلة (2 عناصر بس في صف بيساع 5)؟ مفيش فرق `auto-fit` بيمط العنصرين يملوا الصف، و`auto-fill` بيسيب 3 أعمدة فاضية والعنصرين بحجمهم الأدنى `auto-fill` بيمطهم `auto-fit` بيعمل overflow `auto-fit` = «لم الفاضي». مفيد لما عايز العناصر القليلة تملا المساحة. الاتنين بيعملوا نفس عدد الأعمدة، بس `auto-fit` بيلغي الأعمدة الفاضية فالموجودين يتمطوا.
